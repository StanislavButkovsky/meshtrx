# MeshTRX Desktop

Настольный клиент MeshTRX: то же, что делает Android-приложение, но на
компьютере. Связь с устройством — по Bluetooth LE, голос — Codec2 3200,
как в прошивке.

Linux, Windows и macOS. Разрабатывается и проверяется на Linux.

## Возможности

- **Голос**: передача по удержанию кнопки или пробела, приём с буфером против
  рваного эфира, выбор микрофона и динамика
- **Вызовы**: всем, личный, тревога; приём с принятием и отклонением
- **Сообщения**: широковещательные и адресные, с подтверждением доставки
- **Файлы**: отправка через mesh и приём с сохранением на диск
- **Радар**: абоненты по уровню сигнала
- **Карта**: абоненты по координатам из маяков, без обращения к интернету
- **Настройки**: канал, мощность, позывной, интервал маяка, режим ретранслятора
- **Диагностика**: журнал событий и счётчики — то, чего нет в телефоне

## Запуск из исходников

```bash
python3 -m venv .venv
.venv/bin/pip install -r desktop/requirements.txt
.venv/bin/python desktop/run.py
```

Codec2 берётся из системы:

| Система | Как поставить |
|---------|---------------|
| Debian/Ubuntu | `apt install libcodec2-1.2` (или `libcodec2-dev`) |
| Fedora | `dnf install codec2` |
| macOS | `brew install codec2` |
| Windows | положить `codec2.dll` рядом с программой |

Если библиотека не найдена, клиент скажет об этом при запуске, а не молча
останется без голоса.

## Устройство программы

| Файл | Ответственность |
|------|-----------------|
| `protocol.py` | форматы пакетов BLE — единственное место, где они описаны |
| `link.py` | соединение, бесконечное переподключение, обмен |
| `codec2.py` | обёртка нативного кодека через ctypes |
| `audio.py` | микрофон и динамик, кадры по 20 мс |
| `client.py` | ядро: состояние сети, голос, файлы, вызовы |
| `config.py` | настройки и PIN-коды устройств в домашнем каталоге |
| `ui/` | окно на PySide6: вкладки, радар, карта, тема |

Ядро не зависит от Qt: всю логику можно гонять на живом устройстве без окна —
именно так она и проверялась.

## Что стоит знать

- **PIN спрашивается один раз** на устройство и запоминается. Если устройство
  его отвергнет, сохранённый забывается и клиент спросит заново.
- **При выходе соединение разрывается принудительно**, в том числе по Ctrl+C.
  Брошенное соединение устройство держит до супервизорного таймаута и всё это
  время не рекламируется — снаружи выглядит как «рация пропала».
- **Голос идёт пакетами по 80 мс** (четыре кадра Codec2). Перед
  воспроизведением копится буфер примерно на четверть секунды, иначе речь
  рвётся на каждом опоздании пакета.
- **Своих координат у настольного клиента нет**: на вкладке карты их задают
  вручную, и они же уходят устройству, когда оно их запрашивает для маяка.
